Browser requirement

Web MIDI requires Chrome or Edge on desktop. Firefox and Safari are not supported.

macOS — IAC Driver
  1. Press ⌘ Space, search Audio MIDI Setup
  2. Click Window → Show MIDI Studio
  3. Double-click IAC Driver
  4. Check Device is online → Apply
  5. Add a second bus with + if needed — Bus 1 for GarageBand, Bus 2 for loopback
  6. Reload this page
Keyboard input

Open GarageBand and select your keyboard as the MIDI input. GarageBand routes notes through the IAC bus to this app.
